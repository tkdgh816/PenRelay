# 펜 릴레이 사용 안내

두 앱을 처음 설치하고 같은 공유기에서 등록하는 절차는 [README의 첫 연결 안내](../README.md#처음-연결하기)를 참고하세요.

## 수동 등록과 재연결

태블릿에서 카메라를 사용할 수 없으면 **연결 방식 변경**에서 PC의 주소와 포트를 입력하고 **적용**을 누릅니다. PC의 **기기 초대**를 열고 표시된 PC 지문과 일회용 비밀을 태블릿의 **수동 등록**에 입력합니다. **등록 요청**을 누른 뒤 양쪽 화면의 태블릿 지문이 같으면 PC에서 승인합니다.

첫 인증 이후에는 PC가 마지막 연결 방식과 모니터로 대기하고 태블릿이 등록한 PC에 다시 연결합니다. 태블릿 홈에서 **연결 해제**를 눌렀다면 **연결**을 눌러 재개하세요. **연결 방식 변경**에서 설정을 수정하고 **적용**을 누르면 새 설정을 사용합니다. 변경 중에 설정을 접거나 작업을 선택하면 적용 여부를 묻습니다.

## 공유기 없이 Wi-Fi Direct로 연결하기

1. Windows 대시보드에서 **Wi-Fi Direct (PC 직접 연결)**와 대상 모니터를 선택하고 **연결 대기 시작**을 누릅니다. PC에 Wi-Fi Direct를 지원하는 무선 어댑터가 켜져 있어야 합니다. PC는 이더넷을 사용해도 됩니다.
2. 태블릿에서 **연결 방식 변경 → Wi-Fi Direct (PC 직접 연결) → PC 연결 QR 스캔**을 선택하고 PC 대시보드의 **Wi-Fi Direct 연결 QR**을 비춥니다. 직접 입력하려면 **PC 연결 코드 입력**을 선택해 같은 화면의 20자리 코드를 입력합니다. **연결 코드 표시**를 켜거나 꺼서 입력한 문자를 확인할 수 있습니다.
3. Android의 기기 선택 창에서 `DIRECT-PR-`로 시작하는 그룹을 선택하고 PC에서 **연결 허용**을 누릅니다. 기기에 따라 태블릿이 기존 Wi-Fi를 잠시 떠납니다.
4. 처음 사용하는 태블릿은 PC에서 **기기 초대**를 누르고 태블릿의 **PC 초대 QR 스캔**으로 등록을 진행합니다. 이미 등록한 태블릿은 기존 키로 인증합니다.
5. 무선 그룹을 해제했다면 현재 연결 QR을 다시 스캔하거나 코드를 입력합니다. PC에서 대기를 중지하면 QR과 코드가 사라지고, 다시 시작하면 새로 발급됩니다.

## USB로 연결하기

데이터 전송이 가능한 USB 케이블을 사용하고 PC와 태블릿에서 같은 연결 방식을 선택합니다.

- **USB 테더링**을 사용하려면 태블릿 설정에서 USB 테더링을 켭니다. PC에서는 USB 네트워크 어댑터의 IPv4 주소를 선택하고 태블릿에도 같은 PC 주소를 입력합니다. 주소는 Windows의 `ipconfig`에서 확인할 수 있습니다. Windows 방화벽에서 해당 어댑터의 세션·등록 포트로 들어오는 연결을 허용해야 합니다. 케이블을 다시 꽂은 뒤 연결되지 않으면 테더링 스위치와 할당된 PC 주소를 확인하세요.
- **USB ADB (USB 디버깅)**를 사용하려면 PC에 Android Platform Tools를 설치하고 태블릿의 USB 디버깅을 켠 뒤 이 PC의 디버깅 지문을 승인합니다. PC 대시보드에서 USB ADB를 선택하면 앱이 포트를 관리합니다. 자동으로 찾지 못하면 Windows 앱 설정에서 `adb.exe`를 선택합니다.

연결 경로를 준비한 뒤 새 기기는 초대로 등록하고, 이미 등록한 기기는 기존 등록 정보로 연결합니다.

## 포트 변경과 태블릿 연결 프로필

- PC 대시보드에서 연결 대기를 중지하고 **세션 포트**와 **등록 포트**에 1부터 65535 사이의 서로 다른 번호를 입력한 뒤 대기를 시작합니다. 기본값은 각각 47120과 47121입니다. 태블릿에서는 **PC 연결 → 연결 방식 변경**에서 같은 번호를 입력합니다. 새 기기를 초대 QR로 등록하면 PC가 사용 중인 두 포트가 자동으로 입력됩니다.
- Wi-Fi와 USB 테더링에서는 **최근 주소**를 눌러 최근 사용한 PC 주소를 선택할 수 있습니다. 두 방식이 목록 하나를 공유하며, 최근 주소 10개를 보관합니다. 항목 오른쪽의 **×**를 누르면 해당 주소를 목록에서 삭제합니다.
- 태블릿 홈의 **프로필 → 저장**에서 현재 연결 설정에 이름을 붙입니다. 연결 설정을 편집 중이면 입력란의 값을 저장합니다. **불러오기**에서 이름을 고르면 해당 프로필의 연결 방식, PC 주소, 두 포트가 편집란에 표시됩니다. **적용**을 누르면 연결에 반영됩니다. **프로필 → 삭제**에서 이름을 고르고 삭제를 확인할 수 있습니다.

## 디지타이저에서 입력 위치 맞추기

Windows에서 필기 앱을 대상 모니터에 열고 태블릿의 검은 입력면에 펜촉을 댑니다. 회색 여백에서 시작한 획은 입력되지 않으며 필기 중 여백으로 나가면 접촉이 끝납니다. **90° 회전**은 입력 방향을 시계 방향으로 돌립니다. **비율 전환**으로 종횡비 유지와 전체 영역 매핑 중 하나를 고를 수 있습니다. 위치가 어긋나면 **세 점 보정**을 누르고 차례로 나타나는 흰 점의 중심을 찍으세요. 모니터 구성이 바뀌면 연결 대기를 중지하고 대상 모니터를 다시 선택합니다.

## 캔버스에서 작업하기

- 태블릿에서 **노트** 또는 **페이지**를 짧게 누르면 해당 필름스트립을 열거나 닫습니다. 같은 버튼을 길게 누르면 추가 확인창이 열립니다. 필름스트립 끝의 **＋**는 새 노트나 페이지를 바로 추가합니다.
- 노트나 페이지 카드를 길게 눌러 원하는 위치에 놓으면 순서가 바뀝니다. 노트를 옮기면 안에 있는 페이지도 함께 이동합니다. 노트 카드의 **⋮**에서 이름 변경과 삭제를, 페이지 카드의 **⋮**에서 크기 변경과 삭제를 할 수 있습니다. 노트마다 페이지가 최소 한 장 남습니다.
- Windows 본창에서는 한 줄의 왼쪽에 **페이지**와 **캔버스**, 가운데에 현재 페이지 제목, 오른쪽에 **오버레이**, **복사**, **내보내기**, **공유**가 있습니다. 오버레이에서는 제목 표시줄에서 페이지를 선택하거나 필름스트립을 펼칠 수 있습니다. 고정 아이콘은 **항상 위**, 점 세 개 메뉴는 **본창에서 그림 숨기기**와 **그림 영역 클릭 통과**입니다.
- 연결 중에는 어느 화면에서 선택해도 세 화면이 같은 캔버스를 표시합니다. 필름스트립 열림 상태는 창마다 독립적입니다.
- 태블릿의 **메뉴 → 새 캔버스 기본 크기**에서 **가로 모드**와 **세로 모드**의 너비와 높이를 각각 저장할 수 있습니다. 새 페이지와 추가 캔버스에는 생성 시점의 방향에 해당하는 값이 적용됩니다. 직접 지정하기 전에는 화면 비율에 맞춰 긴 변을 1024 px로 정합니다.
- 태블릿 가로 모드에서는 그리기 도구가 왼쪽 중앙에 있고, 세로 모드에서는 위쪽에 있습니다. 펜이나 지우개를 누르면 마지막에 쓴 종류와 굵기로 돌아갑니다. 현재 도구를 다시 누르면 종류를 선택할 수 있습니다. **굵기**는 선택한 도구에만 적용됩니다. 두 손가락으로 확대하거나 이동할 수 있습니다.
- 도구를 선택한 뒤 **굵기**를 누르면 슬라이더나 **− / +**로 한 단계씩 바꿀 수 있습니다. 필기 도구는 0.2px부터 4px까지 0.2px 간격, 5px부터 96px까지 1px 간격입니다. **펜**에서는 기본 펜·볼펜·사인펜을 고를 수 있고, **연필**에는 흑연 질감이 적용됩니다. **필압 반영**을 0%로 두면 굵기가 일정하고, 100%에서는 기존 필압 반응을 사용합니다.
- 도구 막대의 **실행 취소**와 **다시 실행** 화살표로 현재 캔버스의 필기, 지우개, 전체 지우기를 최대 64단계까지 되돌리거나 다시 적용합니다. 되돌린 뒤 새로 그리면 다시 실행 기록이 초기화됩니다.
- 펜 종류 메뉴에서 기본 펜, 볼펜, 사인펜, 연필, 형광펜을 고릅니다. S펜 옆 버튼을 짧게 눌렀다 떼면 메뉴 맨 아래 **S펜 버튼으로 전환할 펜**에서 체크한 순환 대상 중 다음 펜으로 바뀝니다. 지우개 모드에서는 같은 동작으로 부분 지우개와 획 지우개를 전환합니다.
- 펜촉을 띄우고 S펜 옆 버튼을 0.22초 동안 누르면 마지막으로 선택한 지우개가 켜집니다. 버튼을 누른 채 펜촉을 대면 바로 지울 수 있습니다. 지우는 도중 버튼을 놓으면 펜촉을 뗄 때까지 지우개가 유지됩니다. 필기 중 새로 누른 버튼은 도구 전환에서 제외됩니다. 화면의 **지우개** 버튼을 길게 누르면 캔버스 전체 지우기 확인창이 열립니다. 지우기를 완료하면 마지막 필기 도구로 돌아갑니다.
- **메뉴 → PC에 필기 표시**에서 **실시간 표시**와 **완성된 획 우선 표시**를 선택합니다. 기본값인 실시간 표시는 펜을 움직이는 동안 PC에 획이 보이고, 완성된 획 우선 표시는 짧은 획을 다 쓴 뒤 보여 줍니다. 선택한 설정은 앱을 다시 열어도 유지됩니다. [미리보기 전송 주기와 버전별 변경](CANVAS_PREVIEW.md)
- 캔버스의 **메뉴**에서 홈이나 디지타이저 모드로 이동하고, 현재 캔버스를 PNG·SVG로 내보내거나 PNG로 공유할 수 있습니다. 두 모드 모두 도구 막대의 **연결됨** 또는 **연결 안 됨** 버튼을 누르면 **연결 방식 변경**, 연결·해제, 연결 상태 확인이 가능합니다.
- 디지타이저에서는 대상 모니터와 해상도가 표시됩니다. **90° 회전**, **비율 전환**, **세 점 보정**은 가로 모드에서 왼쪽 중앙, 세로 모드에서 위쪽 도구 막대에 있습니다. **메뉴**에서 홈 또는 캔버스 모드로 이동합니다.
- Windows의 **캔버스**에서 동기화된 페이지를 복사·공유하거나 PNG 또는 SVG로 내보냅니다. 오프라인에서도 마지막 보관함을 열 수 있고, 제목 표시줄 오른쪽의 연결 상태 버튼에서 마지막 동기화 시각을 확인할 수 있습니다. 재연결하면 추가·수정·삭제가 반영됩니다.

## 트레이와 오버레이

메인 창의 **닫기(×)** 를 누르면 연결을 유지한 채 알림 영역으로 숨깁니다. 트레이 아이콘을 클릭하거나 시작 메뉴에서 펜 릴레이를 다시 실행하면 같은 메인 창이 열립니다. 앱과 연결을 모두 종료하려면 트레이 아이콘을 우클릭하고 **종료**를 선택합니다.

오버레이만 보이면 오버레이에만 실시간 필기가 표시됩니다. 캔버스를 보여 주는 창이 하나도 없으면 실시간 필기 전송과 그리기를 쉬고, 확정된 필기와 페이지·캔버스 변경은 계속 PC 보관함에 저장합니다. 연결이 끊긴 뒤에도 마지막 동기화가 완료된 내용을 PC에서 열 수 있습니다.

## 이전 버전에서 옮길 때

0.11.12부터 두 앱은 새 설치 ID와 서명 키를 사용합니다. Windows와 Android에 같은 계열의 배포본을 설치하고 처음 한 번 기기를 등록하세요. 기존 설치본의 필기와 등록 정보는 새 앱으로 이전되지 않습니다. 개발판 MSIX의 공개 서명 인증서는 배포 폴더의 `PenRelay.cer`입니다.

### 0.11.0 필기 보관함 전환

태블릿은 빈 SQLite 보관함에서 시작합니다. 기존 Android `.ink` 파일은 가져오지 않습니다. 두 앱을 0.11.0으로 업데이트하고 처음 동기화하면 같은 태블릿의 이전 PC 보관함 대신 새 보관함이 열립니다. 이후에는 태블릿에서 확정한 획과 편집만 묶어서 PC에 저장합니다. 연결이 끊겨도 PC에서는 마지막으로 저장된 버전을 열거나 PNG·SVG로 내보낼 수 있습니다.
