# 프로젝트 명세

Galaxy Tab S9 FE+와 S펜을 보유한 사용자가 같은 로컬 네트워크의 Windows 11 x64 PC에서 시스템 펜을 쓰거나, 태블릿에서 그리는 그림을 PC에 표시할 수 있게 한다. 한 세션에는 한 기기와 하나의 활성 모드만 둔다. 제품명은 펜 릴레이(Pen Relay)이며 Windows와 Android 앱의 설치·등록 절차는 [사용 안내](../README.md)에 정리한다.

## 범위 경계

화면 미러링, 가상 디스플레이, 가상 HID 커널 드라이버, 루팅, 클라우드 서버는 제외한다. Windows UI 기술은 WinUI 3으로 한정한다. Wi-Fi 연결에 USB 디버깅을 요구하지 않는다. Phase 0의 ADB는 개발용 설치와 기록 추출에 사용한다. 시각 일치는 같은 해상도의 정규 픽셀 버퍼로 판정한다. 모니터 색 관리, 크기 및 디스플레이 물리 지연은 별도 관찰값이다.

완료 기준의 수치 중 제품 목표로 합의되지 않은 값은 [시험 계획](TEST_PLAN.md)에 제안값으로 표시한다. 기기별 옵션은 지원 여부와 실제 값 변화를 각각 측정하며, 기본값 0 하나로 미지원 결론을 내리지 않는다.
