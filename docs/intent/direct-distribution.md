# Windows와 Android 앱 직접 배포

처음 쓰는 사람이 Windows용 MSIX 패키지 하나와 Android용 릴리스 APK 하나를 받아 각 기기에 앱을 설치하고, 두 앱의 화면 안내만 따라 첫 획을 그릴 수 있게 한다.

## 첫 연결

Windows 앱에서 연결 방식과 대상 모니터를 선택하면 태블릿에서 할 다음 동작을 안내한다. 두 앱에서 등록할 상대 기기와 연결 상태를 확인할 수 있어야 한다. 연결에 실패하면 어느 기기에서 무엇을 확인해야 하는지 안내한다.

## 평소 사용

등록한 기기에서 앱을 다시 열면 재연결과 모드 선택이 먼저 보인다. 디지타이저 모드에서는 펜 입력을 받을 모니터를 확인할 수 있다. Canvas 모드에서는 태블릿에 그린 획이 PC에 바로 표시된다.

## 완료 기준

직접 배포할 MSIX와 릴리스 APK를 실제 Windows PC와 갤럭시 탭에 설치한다. 처음 쓰는 사람이 README를 읽거나 터미널 명령을 입력할 필요 없이 화면 안내만으로 다음 과정을 마칠 수 있는지 확인한다.

1. 두 기기를 처음 등록하고 연결 상태를 확인한다.
2. 디지타이저 모드에서 태블릿에 그은 획이 선택한 모니터의 펜 입력으로 전달되는지 확인한다.
3. Canvas 모드에서 태블릿에 그은 획이 PC에 표시되는지 확인한다.
