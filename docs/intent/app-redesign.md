# Windows와 갤럭시 탭의 펜 릴레이 디자인 의도

## 목표

갤럭시 탭과 Windows PC를 함께 쓰는 사람이 두 앱을 열면 연결 결과를 즉시 알아보고 S펜 작업을 시작할 수 있게 한다. 처음 쓰는 사람에게는 다음에 어느 기기에서 무엇을 눌러야 하는지 안내한다. 매일 쓰는 사람은 연결 설정을 다시 고르지 않고 ‘PC에 펜 입력’과 ‘캔버스에 쓰기’ 중 원하는 작업을 시작할 수 있어야 한다.

캔버스 페이지의 원본은 태블릿에 둔다. 사용자는 태블릿에서 페이지를 만들고 편집하며, Windows에서는 동기화된 페이지를 읽기 전용으로 열어 활용한다. 두 앱의 아이콘과 상태 표현은 일관되게 유지하고, 각 화면의 배치와 조작은 해당 플랫폼에 맞춘다.

## 연결 안내와 상태 피드백

- 첫 연결은 Wi-Fi를 먼저 안내하고 USB도 같은 화면에서 선택할 수 있게 한다. Windows에 초대 QR 코드가 뜨면 태블릿에서 ‘PC 초대 QR 스캔’을 누르도록 안내한다.
- 등록한 기기는 마지막으로 인증에 성공한 연결 방식으로 다시 연결한다. 다른 방식을 시도했다가 실패해도 마지막 성공 기록을 유지한다.
- 양쪽 앱은 **연결 대기 중**, **연결 중**, **연결됨**, **연결 실패**, **연결 끊김**을 구분해 표시한다. 인증에 성공하는 순간 양쪽 화면에서 상대 기기 이름과 함께 성공을 알린다. 실패한 화면에는 시도한 연결 방식과 ‘다시 시도’, ‘연결 방식 변경’을 함께 표시한다.
- 기기가 연결된 뒤에도 페이지를 전송하는 동안에는 **동기화 중**을 표시한다. Windows의 페이지 목록과 내용이 태블릿의 확정 상태와 일치하면 **동기화 완료**를 표시한다.

## 화면 디자인

- **Windows** 기본 창에 Mica 배경을 적용하고 WinUI 3 제목 표시줄을 앱 콘텐츠와 통합한다. 대시보드에서는 연결된 태블릿과 펜 입력을 받을 모니터가 한눈에 보여야 한다. 캔버스에서는 페이지 목록을 보며 전환할 수 있고, 현재 그림이 가장 넓은 영역을 차지한다.
- **Android** 차분한 중립색과 하나의 강조색을 사용한다. 홈에서는 ‘PC에 펜 입력’과 ‘캔버스에 쓰기’의 용도를 구분한다. 필기 화면에서는 자주 쓰는 도구를 가장자리의 작은 도구 막대에 두고, 색상·브러시·굵기 선택기는 필요할 때 펼친다.

## 태블릿 필기와 페이지 저장

- 펜·연필·형광펜은 그 결과가 서로 구별되어야 한다. 자유 색상 팔레트에서 원하는 색을 고르고, 굵기는 1픽셀 단위로 조절할 수 있어야 한다. 필압을 반영한 획의 표현은 저장 후에도 유지한다.
- 부분 지우개로 획의 일부를 지우고, 획 지우개로 닿은 획 전체를 지울 수 있다. 페이지 전체 지우기는 현재 페이지의 필기 내용을 비우고 페이지는 유지한다.
- 획 경로와 필압을 벡터 데이터로 보존한다. 큰 태블릿 화면이나 확대된 화면에서도 현재 배율에 맞게 획을 선명하게 그린다.
- 태블릿에 저장한 페이지는 앱을 종료한 뒤 다시 열어 이어 그릴 수 있어야 한다. 태블릿에서 PNG로 내보내거나, 획을 벡터로 유지한 SVG로 내보낼 수 있다.

## Windows에서 페이지 확인과 활용

연결 중에는 태블릿에서 확정한 변경 사항이 Windows에 자동으로 반영된다. 사용자는 Windows에서 동기화된 페이지를 열어 복사하거나 내보내거나 공유할 수 있다.

재연결의 완료 기준은 다음 사용 장면으로 확인한다.

1. 태블릿과 PC를 동기화한 뒤 연결을 끊는다. Windows에서는 마지막으로 동기화한 페이지를 읽을 수 있고, 오프라인 상태와 마지막 동기화 시각을 확인할 수 있다.
2. 오프라인인 태블릿에서 새 페이지를 추가하고, 기존 페이지에서 획을 지우고, 다른 페이지의 필기 내용을 전부 비운다.
3. 두 기기를 다시 연결한다. Windows에 새 페이지가 나타나고, 지운 획은 사라지며, 내용을 비운 페이지는 빈 페이지로 남는다. 이때 두 기기의 페이지 목록과 각 페이지의 내용이 일치해야 한다.

## 제외 범위

- Windows에서 캔버스 페이지를 생성하거나 필기·편집하는 기능
- 두 기기에서 같은 페이지를 편집했을 때의 양방향 충돌 처리
- 클라우드를 통한 페이지 동기화
