# 여러 캔버스와 기기 간 탐색

## 목표

태블릿에서 한 페이지의 필기를 여러 장의 캔버스로 나누어 관리한다. 연결 중에는 태블릿, Windows 본창, 오버레이 어디에서 페이지나 캔버스를 선택해도 세 화면이 같은 캔버스를 표시한다.

## 사용 흐름과 완료 기준

- 태블릿에서 캔버스를 추가하거나 삭제한다. 기존 각 페이지의 그림은 그 페이지의 첫 번째 캔버스로 유지한다.
- 세 화면에는 각각 열고 닫을 수 있는 썸네일 필름스트립을 둔다. 필름스트립의 열림 상태는 각 화면이 독립적으로 관리한다.
- Windows의 기본 연결 상태는 ‘연결됨’과 ‘연결 안 됨’이다. 상태를 누르면 연결 방식, 동기화 상태, 실패 원인을 확인할 수 있다.
- Android 앱의 위아래 가장자리에 블러를 적용하고, 시스템 상태바의 시계와 알림·배터리 아이콘을 쉽게 읽을 수 있도록 배경 대비를 확보한다.
- Windows 오버레이에는 WinUI 3 제목 표시줄을 사용한다. ‘항상 위’는 점 세 개 메뉴 옆의 아이콘 토글로 제공하고, 나머지 옵션은 메뉴에 둔다. 오버레이를 표시하는 동안 본창의 그림만 숨길 수 있으며 본창의 탐색 기능은 유지한다.

## 제외 범위

Windows에서의 필기 및 캔버스 추가·삭제, 양방향 필기 편집은 제외한다. 작업은 앱 구현과 정식 MSIX·APK 패키징까지이며, 기능·성능·실기기 검증 및 설치·업데이트는 사용자가 수행한다.
