# 단계별 로드맵

각 단계의 시험은 모의 상대 또는 기록을 입력으로 시작할 수 있어야 한다. 제품 릴리스 순서와 시험에 필요한 장비를 구분한다.

| 단계 | 만들 것 | 독립 실행 방법과 종료 조건 |
| --- | --- | --- |
| 0 기술 검증 | S펜 센서표와 원시 기록, Windows 펜 생성/수신 호환성표, 모니터·캔버스·지연 기준 실험 | P0-S 1차 관찰과 P0-W 로컬 시험 수행. 센서 반복과 P0-M/C/L 판정이 남아 있음 |
| 1 통신 · 완료 | TCP/TLS, 등록·폐기, 버전 및 세션, 재연결, RTT와 제한된 큐 | [P1-L 통과](TEST_PLAN.md#p1-최종-검증). TLS 루프백, S9 FE+ 실제 Wi-Fi, API 37 에뮬레이터 권한 거부·복구 검증 |
| 2 Digitizer · 구현 | 대상 화면 선택, 보정, PT_PEN 상태기계와 해제 | [P2-A](TEST_PLAN.md#p2-a-디지타이저)에서 직접 필기 중 단절·모드 전환 및 실기기 기록의 두 모니터 교차 검증 통과. 대상 모니터의 물리 분리 시험은 미실행 |
| 3 Canvas · 완료 | Android 오프라인 필기, 임시 획, revision·델타·스냅샷, Win2D 뷰어 | [P3-C 통과](TEST_PLAN.md#p3-c-canvas). S9 FE+에서 연결 중·단절 중 직접 그린 두 획의 최종 해시 일치와 Windows 창 표시 확인 |
| 4 USB · 실기기 검증 | ADB reverse 포트 복구, USB 테더링 경로, 경로별 지연 측정 | [P4-U](TEST_PLAN.md#p4-u-usb)에서 세 경로의 실제 펜 이벤트·픽셀 해시와 지연 대조. 케이블 재연결 시 ADB 자동 복구, 테더링은 사용자가 스위치를 다시 켠 뒤 세션·획 복구 |
| 5 Windows 제품 앱 · 구현 | 연결·모니터 선택, 5개 화면, 설정 복원, 복구 UI, 접근성, MSI, Canvas 오버레이 | [P5-D 실측](TEST_PLAN.md#p5-d--windows-제품-셸과-실제-태블릿). 현재 PC에서 설치·업데이트·제거, 키보드·고대비·복구·오버레이 클릭 통과 및 세 경로 실기기 검증. 새 프로필·깨끗한 Windows 시험은 환경 확보 후 판정 |

## 단계 사이 결정

- Phase 0에서 압력이나 축을 확인하지 못하면 원시 기록과 기기 버전을 보존한다. 옵션 축은 기능 협상에 반영하고 필수 접촉/압력 경로가 실패하면 Mode A 범위를 다시 제안한다. 독립적인 Canvas 시험은 계속할 수 있다.
- 합성 장치는 생성되어도 특정 드로잉 앱이 필압을 사용하지 않을 수 있다. 대상 앱별 Windows Ink 입력 설정과 수신기 증거를 남긴 뒤 호환 대상을 정한다.
- Phase 1은 실제 시스템 주입 권한을 열기 전에 인증과 강제 연결 종료를 시험한다. Phase 2와 3은 서로의 렌더러/주입기 없이 시험할 수 있어야 한다.
- USB는 먼저 개발용 ADB reverse와 USB 테더링에서 같은 세션 계약을 비교한다. 제품 연결 승인은 별도다. 디버깅을 요구하지 않는 방식, Samsung 드라이버 및 Windows 방화벽 조건을 기록한다.
- 배포 형식과 오버레이 도입 여부는 Phase 5에서 결정한다. 개발용 unpackaged 실행이 배포 완료를 의미하지 않는다.

시험별 준비물과 증거 형식은 [시험 계획](TEST_PLAN.md), 기술 선택의 근거는 [결정 기록](DECISIONS.md)에 있다.

## 추후 검토할 캔버스 도구

아래 도구는 후속 후보로 보관하며 도입 시점은 추후 결정한다.

| 후보 | 표현하려는 특징 |
| --- | --- |
| 파인라이너·제도펜 | 작은 글씨와 도면에 쓰는 일정한 폭의 가는 선 |
| G펜·붓펜 | 필압에 따라 가늘게 시작하거나 끝나고 중간이 굵어지는 획 |
| 드라이 잉크·마른 붓 | 잉크 사이로 종이가 비치거나 획 방향을 따라 갈라지는 붓털 자국 |
| 목탄·분필·파스텔 | 종이 결에 가루가 걸리는 거친 선과 넓은 명암·색면 |
| 수채화 | 투명한 덧칠, 색이 모이는 가장자리와 젖은 색의 혼합 |
| 에어브러시 | 중심에서 바깥으로 옅어지는 경계 없는 음영 |

획의 예시는 [Krita 브러시 자료](https://docs.krita.org/en/reference_manual/krita_4_preset_bundle.html)와 [Procreate 브러시 라이브러리](https://help.procreate.com/procreate/handbook/5.4/brushes/brush-library)에서 확인할 수 있다.
