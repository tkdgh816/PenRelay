# 펜 릴레이의 개발 동기와 사용자 가치

PC에서 작업하다 보면 문장으로 설명하는 데 한참 걸릴 내용을 상자 몇 개와 화살표만으로 표현할 수 있는 순간이 있습니다. 손에 닿는 곳에 갤럭시 탭과 S펜이 있어도, 한 번 보여 줄 스케치를 캡처하고 파일로 저장해 PC로 옮겨야 한다면 결국 글로 풀어 쓰게 됩니다. 펜 릴레이는 그때 포기했던 손그림과 필기를 하던 일에 바로 쓸 수 있게 하려고 시작했습니다.

## 한 장의 스케치에서 확장된 세 가지 쓰임

- **PC에서 하던 작업에 그림을 붙여넣습니다.** 예를 들어 AI와 화면 구성을 논의하다가 원하는 배치를 태블릿에 그리고, Windows 캔버스에서 페이지를 복사해 이미지 입력을 지원하는 대화창에 붙여넣습니다. “오른쪽 목록만 이렇게 옮겨 주세요”라는 한 문장이면 설명을 이어갈 수 있습니다. 손글씨 메모, 그래프, 마인드맵도 같은 방식으로 오피스 문서나 브라우저의 편집기에 넣을 수 있습니다. 파일이 필요할 때는 PC에서 PNG나 SVG로 저장합니다.
- **발표에서는 그리는 과정까지 보여 줍니다.** 발표자는 태블릿에 그래프의 축을 그리고 곡선을 하나씩 더합니다. 청중은 PC에 연결된 외부 화면에서 설명과 같은 순서로 그래프가 완성되는 모습을 봅니다. 질문이 나오면 그 자리에서 표시하거나 마인드맵에 가지를 덧붙일 수 있습니다.
- **Windows 그리기 앱에서는 태블릿을 펜 입력 도구로 씁니다.** 앞의 두 장면에서는 태블릿의 캔버스에 원본이 남습니다. 디지타이저 모드에서는 연결된 태블릿이 선택한 모니터의 Windows 펜 역할을 하므로, 사용자는 익숙한 PC 앱의 브러시로 그 앱의 문서에 직접 그립니다.

## 누구에게 어떤 이유로 매력적인가

| 사용자의 상황 | 기대하는 가치 |
| --- | --- |
| 갤럭시 탭과 S펜이 있지만 업무는 주로 펜 입력이 없는 PC에서 하는 사람 | 이미 가진 태블릿을 책상에 두고, 문서나 대화에 짧은 설명 그림이 필요할 때마다 꺼내 쓸 이유가 생깁니다. |
| PC 작업과 따로 쓰게 될까 봐 태블릿 구매를 망설인 사람 | 평소 쓰는 Windows 앱에서 손그림을 활용하고 발표에도 쓸 수 있다는 점이 구매를 고려할 구체적인 이유가 될 수 있습니다. 실제 구매 결정에 미치는 영향은 이런 장면이 얼마나 자주 생기는지에 따라 달라집니다. |
| 생각이 떠오른 순간에 그려 가며 정리하거나 설명하고 싶은 사람 | 그림을 어디에 저장하고 어떻게 전달할지 정하기 전에 먼저 그릴 수 있습니다. 혼자 생각할 때는 스케치로 남기고, 필요해진 순간에는 대화나 발표에 그대로 사용합니다. |

## 연결 과정도 사용 경험의 일부입니다

그림을 옮기는 수고를 줄여도, 한 줄 그릴 때마다 PC를 찾거나 연결을 기다려야 한다면 펜을 들기 어렵습니다. 다음은 설치부터 연결 복구까지 앱을 기획하고 개선할 때 지키고 싶은 기준입니다.

| 장면 | 사용자가 경험해야 할 일 |
| --- | --- |
| 설치와 첫 연결 | 두 기기에 무엇을 설치하고 어느 화면에서 다음 조작을 하는지 알 수 있습니다. 기기 등록이 끝나면 첫 획을 그어 의도한 PC에 나타나는 것까지 확인할 수 있습니다. |
| 다음 날 다시 사용 | 등록한 PC가 준비되어 있으면 이전 설정으로 다시 연결됩니다. 사용자는 매번 초대 QR을 찾거나 주소를 입력할 필요 없이 캔버스를 열고 그릴 수 있습니다. |
| PC가 꺼져 있거나 필기 중 연결이 끊김 | 태블릿에서는 새 그림을 시작하고 기존 그림도 계속 고칠 수 있습니다. 발표 중에는 펜을 멈추지 않고도 태블릿에 저장된 내용이 어디까지 PC에 전달됐는지 알 수 있어야 합니다. |
| 나중에 다시 연결 | 별도의 전송 조작 없이 오프라인에서 추가하거나 수정한 내용이 PC에 반영됩니다. 태블릿 앱을 닫았다가 열어도 그 페이지를 이어서 보고, PC에서 복사할 수 있어야 합니다. |

현재 사용 안내에 따르면, 첫 인증 이후에는 PC가 마지막 설정으로 대기하고 태블릿이 등록된 PC에 재연결합니다. 사용자가 직접 연결을 해제한 경우에는 다시 연결을 선택해야 합니다. Wi-Fi Direct 그룹이 해제된 경우에는 무선 그룹에 다시 가입하는 단계가 필요하며 기존 기기 등록은 유지됩니다. 캔버스 원본은 태블릿에 남고, 연결이 끊긴 동안 PC에서는 마지막으로 동기화된 내용을 볼 수 있습니다. [설치와 연결 방법](../README.md#처음-연결하기) · [프로젝트 명세](PROJECT_SPEC.md)

## 유용성을 판단할 장면

사용자에게 물어보고 싶은 질문은 **“예전 같으면 글로만 설명했을 순간에 실제로 펜을 들었나요?”**입니다. 예를 들어 PC가 꺼져 있을 때 떠오른 배치를 태블릿에 그려 두고 앱을 닫습니다. 나중에 PC에서 일을 시작했을 때 별도로 파일을 옮기지 않고 그 스케치를 AI 대화나 문서에 붙여넣을 수 있다면, 아이디어가 떠오른 순간과 그 아이디어를 쓸 순간이 자연스럽게 이어집니다.
