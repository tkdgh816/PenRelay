# 펜 릴레이 (Pen Relay)

펜 릴레이는 Galaxy Tab의 S펜을 Windows PC에서 활용하는 앱입니다. PC의 드로잉 앱에 직접 펜으로 입력하거나, 태블릿에 필기한 내용을 PC 화면에 띄워 발표할 수 있습니다.

| 하고 싶은 일 | 사용할 모드 |
| --- | --- |
| PC에서 연 그림이나 문서에 S펜으로 쓰기 | **디지타이저** · 태블릿의 검은 입력면에 쓰면 선택한 모니터의 Windows 앱이 펜 위치와 필압을 받습니다. |
| 태블릿 노트를 PC에 띄우거나 그림 파일로 옮기기 | **캔버스** · 태블릿에서 그리는 획이 PC에 표시됩니다. 연결이 끊겨도 태블릿에서 계속 쓰고, 다시 연결하면 PC 보관함에 반영됩니다. |

## 설치하기

- **태블릿** · Android 13 이상이 필요합니다. 실기기에서 확인한 조합은 Galaxy Tab S9 FE+와 S펜입니다. 태블릿에 펜 릴레이 APK를 설치합니다.
- **PC** · Windows 11 x64에 같은 배포 버전의 서명된 MSIX를 설치합니다. 개발판(`-Dev.msix`)에는 x64 .NET 10 런타임과 x64 Windows App Runtime 2(2.7.0.0 이상)가 필요합니다. PC에서 배포자의 MSIX 서명 인증서를 신뢰해야 하며, 개발판의 공개 인증서 이름은 `PenRelay.cer`입니다.

이 저장소에는 APK와 MSIX가 포함되어 있지 않습니다. 설치 파일이 없다면 Windows 앱을 빌드해 실행하고 Android 앱을 태블릿에 설치하세요. 두 플랫폼의 명령과 서명된 설치 파일을 만드는 방법은 [개발 환경과 빌드](docs/DEVELOPMENT.md)에 있습니다.

## 처음 연결하기

같은 공유기에 연결된 PC와 태블릿을 기준으로 합니다. PC는 유선 LAN으로 연결해도 됩니다.

1. **PC에서** 펜 릴레이를 열고 **Wi-Fi (같은 공유기)**, 태블릿에서 접근할 수 있는 **PC 대기 주소**, **펜 입력을 받을 모니터**를 선택합니다. **연결 대기 시작 → 기기 초대**를 눌러 초대 QR을 띄웁니다.
2. **태블릿에서** 펜 릴레이를 열고 **PC 초대 QR 스캔**으로 해당 QR을 읽습니다. 표시된 PC 이름과 지문을 확인하고 **등록 요청**을 누릅니다.
3. **PC에서** 양쪽 화면에 표시된 태블릿 지문이 일치하는지 확인한 뒤 **지문 확인 후 승인**을 누릅니다. 태블릿 홈의 **PC 연결**에서 연결 상태를 확인합니다.

첫 등록 이후에는 PC가 마지막 설정으로 대기하고 태블릿이 다시 연결합니다. 공유기가 없는 곳에서는 **Wi-Fi Direct**로 무선 그룹에 먼저 가입한 뒤 기기를 등록하세요. 케이블을 쓸 때는 **USB 테더링** 또는 **USB ADB**를 선택할 수 있습니다. [Wi-Fi Direct 연결](docs/USER_GUIDE.md#공유기-없이-wi-fi-direct로-연결하기) · [USB 연결](docs/USER_GUIDE.md#usb로-연결하기) · [QR 없이 수동 등록](docs/USER_GUIDE.md#수동-등록과-재연결)

## 펜으로 작업하기

- **디지타이저** · PC의 대상 모니터에 필기할 앱을 열고 태블릿에서 **디지타이저**를 선택합니다. 검은 입력면에 짧은 획을 그어 보세요. 화면 방향이나 펜 위치가 맞지 않으면 태블릿 도구 막대의 **90° 회전**, **비율 전환**, **세 점 보정**으로 조정합니다.
- **캔버스** · 태블릿에서 **캔버스**를 선택하고 흰 페이지에 씁니다. PC의 캔버스 창에서 같은 필기를 볼 수 있고, **오버레이**를 열면 다른 앱 위에도 띄울 수 있습니다. **내보내기**로 현재 그림을 PNG 또는 SVG 파일로 저장합니다. 오프라인에서는 태블릿에서 계속 편집하거나 PC에서 마지막으로 동기화된 페이지를 열 수 있습니다.

노트와 페이지 관리, S펜 버튼과 지우개 사용법, 연결 프로필, 트레이에서 앱을 종료하는 방법은 [상세 사용 안내](docs/USER_GUIDE.md)에 있습니다.

## 기술과 문서

| 구성 | 기술과 역할 |
| --- | --- |
| [Android 앱](android/) | Kotlin으로 S펜 입력을 수집하고, 캔버스 원본을 태블릿의 SQLite 보관함에 저장합니다. |
| [Windows 앱](windows/) | C#과 WinUI 3로 구현했습니다. 디지타이저 입력을 Windows 펜 이벤트로 전달하고, Win2D로 캔버스를 그립니다. |
| 기기 간 통신 | 등록된 태블릿과 PC가 TLS로 서로 인증한 뒤 선택한 연결 경로로 펜 입력이나 캔버스 변경을 전송합니다. |
