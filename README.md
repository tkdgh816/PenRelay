## 제품 이름과 설치 파일

사용자 화면에는 한국어 **펜 릴레이**, 영어 **Pen Relay**로 표시합니다. 저장소 이름은 `penrelay`이고 소스와 배포 파일에는 `PenRelay`를 사용합니다. Windows 솔루션은 [PenRelay.slnx](windows/PenRelay.slnx), Android 프로젝트는 [android](android/)에서 엽니다.

0.11.12부터 두 앱은 새 설치 ID와 서명 키를 사용합니다. Windows와 Android에 같은 계열의 배포본을 설치하고 처음 한 번 기기를 등록하세요. 기존 설치본의 필기와 등록 정보는 새 앱으로 이전되지 않습니다. 개발판 MSIX의 공개 서명 인증서는 배포 폴더의 `PenRelay.cer`입니다.

## Windows 앱에서 시작하기

1. Windows 11 x64에서 서명된 MSIX를 열어 설치하고 시작 메뉴의 **펜 릴레이**를 엽니다. 기본 개발판(`-Dev.msix`)에는 x64 .NET 10 런타임과 x64 Windows App Runtime 2 계열(2.7.0.0 이상)이 필요합니다. 설치할 PC가 MSIX 서명 인증서를 신뢰해야 합니다. 태블릿에는 릴리스 APK를 설치하고 **펜 릴레이**를 엽니다.
2. PC에서 **연결 방식**, **PC 대기 주소**, **펜 입력을 받을 모니터**를 선택한 뒤 **연결 대기 시작 → 기기 초대**를 누릅니다. Wi-Fi (같은 공유기)에서는 PC와 태블릿이 같은 로컬 네트워크를 사용합니다. Wi-Fi Direct (PC 직접 연결)는 아래의 무선 그룹 가입을 먼저 진행합니다. USB 테더링에서는 태블릿에서 테더링을 켜고 PC의 USB 어댑터 주소를 선택합니다.
3. 태블릿에서 **PC 초대 QR 스캔**으로 PC 화면을 비추고 표시된 PC 이름과 지문을 확인한 뒤 **등록 요청**을 누릅니다. 양쪽의 태블릿 지문이 같으면 PC에서 **지문 확인 후 승인**을 누릅니다. 카메라를 쓸 수 없으면 태블릿의 **연결 방식 변경**에서 주소와 포트를 적용한 뒤, **수동 등록**에서 PC 지문과 일회용 비밀을 입력합니다.
4. 등록이 끝나면 태블릿이 PC에 연결합니다. 태블릿 홈의 **PC 연결**에서 연결 상태, 등록된 PC, 방식과 주소를 확인하고 **디지타이저**를 선택합니다. 태블릿에 표시된 대상 모니터에서 필기 앱을 열고 검은 입력면에 S펜으로 씁니다. **캔버스**를 선택하면 PC에도 캔버스가 열립니다. 태블릿의 흰 면에 S펜으로 그려 확인합니다.
5. 인증에 성공한 다음 실행부터는 PC가 마지막 연결 방식과 모니터로 대기하고 태블릿이 등록한 PC에 다시 연결합니다. 태블릿 메인 페이지에서 **연결 해제**를 누르면 다시 **연결**을 선택할 때까지 자동 연결을 멈춥니다. **연결 방식 변경**을 펼쳐 수정한 뒤 **적용**하면 새 설정을 사용합니다. 변경 중 설정을 접거나 작업을 선택하면 적용 여부를 묻습니다.

### 트레이와 오버레이

메인 창의 **닫기(×)** 를 누르면 연결을 유지한 채 알림 영역으로 숨깁니다. 트레이 아이콘을 클릭하거나 시작 메뉴에서 펜 릴레이를 다시 실행하면 같은 메인 창이 열립니다. 앱과 연결을 모두 종료하려면 트레이 아이콘을 우클릭하고 **종료**를 선택합니다.

오버레이만 보이면 오버레이에만 실시간 필기가 표시됩니다. 캔버스를 보여 주는 창이 하나도 없으면 실시간 필기 전송과 그리기를 쉬고, 확정된 필기와 페이지·캔버스 변경은 계속 PC 보관함에 저장합니다. 두 기기에 0.10.22 이상을 설치하면 이 동작을 사용할 수 있습니다. 연결이 끊긴 뒤에도 마지막 동기화가 완료된 내용을 PC에서 열 수 있습니다.

### 0.11.0 필기 보관함 전환

태블릿은 빈 SQLite 보관함에서 시작합니다. 기존 Android `.ink` 파일은 가져오지 않습니다. 두 앱을 0.11.0으로 업데이트하고 처음 동기화하면 같은 태블릿의 이전 PC 보관함 대신 새 보관함이 열립니다. 이후에는 태블릿에서 확정한 획과 편집만 묶어서 PC에 저장합니다. 연결이 끊겨도 PC에서는 마지막으로 저장된 버전을 열거나 PNG·SVG로 내보낼 수 있습니다.

### 포트 변경과 태블릿 연결 프로필

- PC 대시보드에서 연결 대기를 중지하고 **세션 포트**와 **등록 포트**에 1부터 65535 사이의 서로 다른 번호를 입력한 뒤 대기를 시작합니다. 기본값은 각각 47120과 47121입니다. 태블릿에서는 **PC 연결 → 연결 방식 변경**에서 같은 번호를 입력합니다. 새 기기를 초대 QR로 등록하면 PC가 사용 중인 두 포트가 자동으로 입력됩니다.
- Wi-Fi와 USB 테더링에서는 **최근 주소**를 눌러 최근 사용한 PC 주소를 선택할 수 있습니다. 두 방식이 목록 하나를 공유하며, 최근 주소 10개를 보관합니다. 항목 오른쪽의 **×**를 누르면 해당 주소를 목록에서 삭제합니다.
- 태블릿 홈의 **프로필 → 저장**에서 현재 연결 설정에 이름을 붙입니다. 연결 설정을 편집 중이면 입력란의 값을 저장합니다. **불러오기**에서 이름을 고르면 해당 프로필의 연결 방식, PC 주소, 두 포트가 편집란에 표시됩니다. **적용**을 누르면 연결에 반영됩니다. **프로필 → 삭제**에서 이름을 고르고 삭제를 확인할 수 있습니다.

### 공유기 없이 Wi-Fi Direct로 연결하기

1. Windows 대시보드에서 **Wi-Fi Direct (PC 직접 연결)**와 대상 모니터를 선택하고 **연결 대기 시작**을 누릅니다. PC에 Wi-Fi Direct를 지원하는 무선 어댑터가 켜져 있어야 합니다. PC는 이더넷을 사용해도 됩니다.
2. 태블릿에서 **연결 방식 변경 → Wi-Fi Direct (PC 직접 연결) → PC 연결 QR 스캔**을 선택하고 PC 대시보드의 **Wi-Fi Direct 연결 QR**을 비춥니다. 직접 입력하려면 **PC 연결 코드 입력**을 선택해 같은 화면의 20자리 코드를 입력합니다. **연결 코드 표시**를 켜거나 꺼서 입력한 문자를 확인할 수 있습니다.
3. Android의 기기 선택 창에서 `DIRECT-PR-`로 시작하는 그룹을 선택하고 PC에서 **연결 허용**을 누릅니다. 기기에 따라 태블릿이 기존 Wi-Fi를 잠시 떠납니다.
4. 처음 사용하는 태블릿은 PC에서 **기기 초대**를 누르고 태블릿의 **PC 초대 QR 스캔**으로 등록을 진행합니다. 이미 등록한 태블릿은 기존 키로 인증합니다.
5. 무선 그룹을 해제했다면 현재 연결 QR을 다시 스캔하거나 코드를 입력합니다. PC에서 대기를 중지하면 QR과 코드가 사라지고, 다시 시작하면 새로 발급됩니다.


### 캔버스에서 작업하기

- 태블릿에서 **노트** 또는 **페이지**를 짧게 누르면 해당 필름스트립을 열거나 닫습니다. 같은 버튼을 길게 누르면 추가 확인창이 열립니다. 필름스트립 끝의 **＋**는 새 노트나 페이지를 바로 추가합니다.
- 노트나 페이지 카드를 길게 눌러 원하는 위치에 놓으면 순서가 바뀝니다. 노트를 옮기면 안에 있는 페이지도 함께 이동합니다. 노트 카드의 **⋮**에서 이름 변경과 삭제를, 페이지 카드의 **⋮**에서 크기 변경과 삭제를 할 수 있습니다. 노트마다 페이지가 최소 한 장 남습니다.
- Windows 본창에서는 한 줄의 왼쪽에 **페이지**와 **캔버스**, 가운데에 현재 페이지 제목, 오른쪽에 **오버레이**, **복사**, **내보내기**, **공유**가 있습니다. 오버레이에서는 제목 표시줄에서 페이지를 선택하거나 필름스트립을 펼칠 수 있습니다. 고정 아이콘은 **항상 위**, 점 세 개 메뉴는 **본창에서 그림 숨기기**와 **그림 영역 클릭 통과**입니다.
- 연결 중에는 어느 화면에서 선택해도 세 화면이 같은 캔버스를 표시합니다. 필름스트립 열림 상태는 창마다 독립적입니다.
- 태블릿의 **메뉴 → 새 캔버스 기본 크기**에서 **가로 모드**와 **세로 모드**의 너비와 높이를 각각 저장할 수 있습니다. 새 페이지와 추가 캔버스에는 생성 시점의 방향에 해당하는 값이 적용됩니다. 직접 지정하기 전에는 화면 비율에 맞춰 긴 변을 1024 px로 정합니다.
- 태블릿 가로 모드에서는 그리기 도구가 왼쪽 중앙에 있고, 세로 모드에서는 위쪽에 있습니다. 펜이나 지우개를 누르면 마지막에 쓴 종류와 굵기로 돌아갑니다. 현재 도구를 다시 누르면 종류를 선택할 수 있습니다. **굵기**는 선택한 도구에만 적용됩니다. 두 손가락으로 확대하거나 이동할 수 있습니다.
- 도구를 선택한 뒤 **굵기**를 누르면 슬라이더나 **− / +**로 한 단계씩 바꿀 수 있습니다. 필기 도구는 0.2px부터 4px까지 0.2px 간격, 5px부터 96px까지 1px 간격입니다. **펜**에서는 기본 펜·볼펜·사인펜을 고를 수 있고, **연필**에는 흑연 질감이 적용됩니다. **필압 반영**을 0%로 두면 굵기가 일정하고, 100%에서는 기존 필압 반응을 사용합니다.
- 도구 막대의 **실행 취소**와 **다시 실행** 화살표로 현재 캔버스의 필기, 지우개, 전체 지우기를 최대 64단계까지 되돌리거나 다시 적용합니다. 되돌린 뒤 새로 그리면 다시 실행 기록이 초기화됩니다.
- 펜 종류 메뉴에서 기본 펜, 볼펜, 사인펜, 연필, 형광펜을 고릅니다. S펜 옆 버튼을 짧게 눌렀다 떼면 메뉴 맨 아래 **S펜 버튼으로 전환할 펜**에서 체크한 순환 대상 중 다음 펜으로 바뀝니다. 지우개 모드에서는 같은 동작으로 부분 지우개와 획 지우개를 전환합니다.
- 펜촉을 띄우고 S펜 옆 버튼을 0.22초 동안 누르면 마지막으로 선택한 지우개가 켜집니다. 버튼을 누른 채 펜촉을 대면 바로 지울 수 있습니다. 지우는 도중 버튼을 놓으면 펜촉을 뗄 때까지 지우개가 유지됩니다. 필기 중 새로 누른 버튼은 도구 전환에서 제외됩니다. 화면의 **지우개** 버튼을 길게 누르면 캔버스 전체 지우기 확인창이 열립니다. 지우기를 완료하면 마지막 필기 도구로 돌아갑니다.
- **메뉴 → PC에 필기 표시**의 기본값은 **실시간 표시**입니다. **완성된 획 우선 표시**를 선택하면 1초 안에 마친 획은 펜을 뗄 때 PC에 보냅니다. 계속 그리면 첫 1초에 그동안의 획을 보내고, 이후에는 250ms마다 새로 그린 부분만 보냅니다. 부분 지우개와 획 지우개도 같은 주기로 PC에 반영됩니다. 지우는 중 입력을 취소하면 PC에서도 지우기 전 모습으로 돌아갑니다. 지우개 미리보기는 양쪽 앱 0.11.7부터 지원합니다. 선택한 설정은 앱을 다시 열어도 유지됩니다.
- 캔버스의 **메뉴**에서 홈이나 디지타이저 모드로 이동하고, 현재 캔버스를 PNG·SVG로 내보내거나 PNG로 공유할 수 있습니다. 두 모드 모두 도구 막대의 **연결됨** 또는 **연결 안 됨** 버튼을 누르면 **연결 방식 변경**, 연결·해제, 연결 상태 확인이 가능합니다.
- 디지타이저에서는 대상 모니터와 해상도가 표시됩니다. **90° 회전**, **비율 전환**, **세 점 보정**은 가로 모드에서 왼쪽 중앙, 세로 모드에서 위쪽 도구 막대에 있습니다. **메뉴**에서 홈 또는 캔버스 모드로 이동합니다.
- Windows의 **캔버스**에서 동기화된 페이지를 복사·공유하거나 PNG 또는 SVG로 내보냅니다. 오프라인에서도 마지막 보관함을 열 수 있고, 제목 표시줄 오른쪽의 연결 상태 버튼에서 마지막 동기화 시각을 확인할 수 있습니다. 재연결하면 추가·수정·삭제가 반영됩니다.


### 직접 배포본 만들기

Windows는 Windows SDK 10.0.26100.0와 현재 사용자 인증서 저장소의 코드서명 인증서를 사용합니다. Android는 릴리스 키와 키 저장소 암호를 사용합니다. 다음은 빌드 PC에서만 실행합니다. 설치 파일은 `artifacts/direct/` 아래 각 플랫폼의 버전 폴더에 생성됩니다.

```powershell
.\windows\Installer\Build-Msix.ps1 -CertificateThumbprint $thumbprint
# 두 런타임을 포함한 배포본이 필요할 때
.\windows\Installer\Build-Msix.ps1 -CertificateThumbprint $thumbprint -SelfContained
# PENRELAY_KEYSTORE_PASSWORD 환경 변수로 키 저장소 암호를 전달합니다.
.\android\Build-Release.ps1 -KeyStore $keystore -Alias penrelay
```

## Canvas 전용 창으로 시작하기

1. 아래 Windows 빌드 명령으로 앱을 빌드한 뒤 `PenRelay.Desktop.exe --canvas <PC의 LAN 주소>`를 실행합니다. 세션 포트는 47120, 등록 포트는 47121입니다. 두 모드를 함께 쓰려면 아래 모니터 선택 창에서 **호스트 열기**를 누릅니다.
2. 처음 연결할 때는 PC의 **기기 초대**를 누릅니다. 태블릿 연결 앱에 PC 주소, **준비** 행의 지문과 **초대** 행의 비밀을 입력하고 **수동 등록 → 등록 요청**을 누릅니다. 양쪽 기기 지문을 대조한 다음 PC에서 **지문 확인 후 승인**을 누릅니다.
3. 태블릿에서 **연결 → 캔버스**를 누르고 흰 면에 S펜으로 그립니다. 그리는 동안 PC에는 미리보기가 나타나고, 펜을 떼면 PC 창에 확정 revision과 SHA-256이 표시됩니다.
4. 도구 막대의 **연결됨 → 연결 해제**를 누르고 계속 그린 뒤 **연결 안 됨 → 연결**을 누르면 그동안의 획까지 복구됩니다. 일시적인 통신 장애는 자동으로 재시도합니다. 오프라인에서 먼저 시작할 때는 연결 설정 화면의 **캔버스**를 바로 누르면 됩니다.

페이지 원본은 태블릿 앱의 내부 저장소에 있습니다. 전용 창에서는 현재 페이지의 실시간 필기를 보고, Windows 기본 창의 **캔버스**에서는 동기화된 전체 페이지를 열 수 있습니다.

## S펜을 Windows 펜으로 사용하기

1. 저장소의 `windows` 폴더에서 아래 명령으로 모니터 선택 창을 엽니다.

   ```powershell
   dotnet build .\PenRelay.Desktop\PenRelay.Desktop.csproj -p:Platform=x64
   .\PenRelay.Desktop\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\PenRelay.Desktop.exe --digitizer
   ```

2. **펜 입력을 받을 모니터**와 태블릿에서 접근 가능한 **PC 주소**를 선택하고 **호스트 열기**를 누릅니다. Android 연결 앱을 설치하고 위의 **기기 초대** 절차로 태블릿을 등록합니다.
3. 태블릿에서 **연결 → 디지타이저**을 누르고 검은 영역에 S펜을 댑니다. 회색 여백에서 시작한 획은 무시되며, 필기 중 여백으로 나가면 접촉이 끝납니다. **90° 회전**은 시계 방향, **비율 전환**은 종횡비 유지와 전체 영역 매핑 사이를 전환합니다. **세 점 보정**을 누르면 차례로 나타나는 흰 점의 중심을 펜으로 찍습니다.
4. **캔버스** 또는 **연결됨 → 연결 해제**로 펜 입력을 종료합니다. 앱을 벗어나도 접촉이 해제됩니다. 모니터 구성이 바뀌면 호스트 창을 닫고 대상 모니터를 다시 선택합니다.

## USB로 연결하기

**제품 대시보드**에서 ADB reverse를 고르면 Windows 앱이 포트를 관리합니다. 아래는 이전 개발용 창을 단독 실행할 때 사용하는 방식입니다. 데이터 케이블을 연결하고 이 PC의 USB 디버깅 지문을 승인한 뒤 저장소 루트에서 다음 명령을 실행해 둡니다. Python 3과 Android Platform Tools가 필요합니다. SDK가 다른 위치에 있으면 `--adb 경로`로 지정합니다.

```powershell
python -X utf8 windows/usb_reverse.py
```

1. Windows 모니터 선택 창에서 **127.0.0.1**과 대상 모니터를 선택해 호스트를 엽니다. Canvas만 사용한다면 `PenRelay.Desktop.exe --canvas 127.0.0.1`로 열 수 있습니다.
2. 태블릿에서 **USB ADB (USB 디버깅)**를 선택합니다. 기본 세션 포트는 47120, 등록 포트는 47121입니다. 처음 사용하는 PC라면 **수동 등록 → 등록 요청**으로 양쪽 지문을 확인합니다. 같은 Windows 사용자 키로 이미 등록했다면 바로 **연결**을 누릅니다.
3. **디지타이저** 또는 **캔버스**를 선택합니다. 케이블을 다시 꽂으면 실행 중인 Python 도구가 같은 태블릿의 포트를 복원하고 앱이 새 TLS 세션을 엽니다. 도구를 끝내려면 Ctrl+C를 누릅니다.

**USB 테더링**은 태블릿의 연결 설정에서 USB 테더링을 켜고 Windows의 `ipconfig`에서 새 USB 네트워크 어댑터의 IPv4 주소를 확인합니다. Windows 호스트에서 그 주소를 선택하고 태블릿에서도 **USB · 테더링**을 선택해 같은 주소를 입력합니다. 이 경로는 제품 앱에서 USB 디버깅이나 Python을 요구하지 않습니다. 태블릿이 USB 네트워크를 제공하고 Windows 방화벽이 해당 어댑터에서 호스트 포트로 들어오는 연결을 허용해야 합니다. 뺐다 꽂은 뒤에는 테더링 스위치와 PC의 할당 주소를 확인하세요. 주소가 바뀌었다면 새 주소로 호스트를 열고 앱의 주소도 갱신합니다.

Galaxy Tab S9 FE+ 실측에서 ADB reverse는 케이블을 다시 꽂으면 자동 복구됐습니다. 테더링은 다시 꽂을 때 스위치가 꺼졌고, **USB 테더링을 다시 켜면** 같은 PC 주소로 앱이 연결돼 오프라인 획까지 복구됐습니다. [경로별 지연과 복구 시험](docs/TEST_PLAN.md#p4-u-usb)

## P1 연결하기

1. PC와 태블릿을 같은 LAN에 연결합니다. PC에서 다음 명령을 실행하고 태블릿이 접근할 수 있는 PC 주소를 입력합니다.

   ```powershell
   Set-Location windows
   dotnet build .\SessionFixture\SessionFixture.csproj
   $pcAddress = Read-Host 'PC의 LAN 주소'
   .\SessionFixture\bin\Debug\net10.0\SessionFixture.exe serve $pcAddress 47120 47121
   ```

2. 새 터미널에서 저장소의 `android` 폴더로 이동해 `.\gradlew.bat :app:installDebug`를 실행하거나 `:app:assembleDebug`로 만든 APK를 태블릿에 설치합니다. **펜 릴레이** 앱에 PC 주소, 세션 포트와 등록 포트를 입력합니다.
3. PC 콘솔에 `invite`를 입력합니다. 태블릿에 PC의 **준비** 행 마지막에 있는 공개키 지문과 **초대** 행의 비밀을 입력하고 **수동 등록 → 등록 요청**을 누릅니다. API 37에서 로컬 네트워크 권한을 요청하면 허용합니다. 거부한 경우 앱의 **권한 설정**에서 복구할 수 있습니다.
4. 태블릿에 표시된 **기기 지문**이 PC의 **승인대기** 지문과 같은지 확인한 뒤 PC에 `approve <기기 지문>`을 입력합니다. 태블릿에 등록 완료가 표시되면 **연결**을 누릅니다. 이후 같은 PC에 연결할 때는 주소와 세션 포트만 필요합니다.
5. PC의 `disconnect`로 일시 단절과 자동 재접속을, `list`와 `revoke <기기 지문>`으로 등록 폐기를 확인합니다. 폐기하면 앱이 재등록 대기로 전환됩니다. 호스트 종료는 `stop`입니다.

PC는 지정한 주소의 두 TCP 포트에서 대기합니다. 호스트를 다시 시작해도 현재 Windows 사용자의 키와 등록 목록을 사용합니다. Phase 0 센서 앱과 로컬 펜 진단은 각각 독립 실행할 수 있습니다.

[WinUI 개발 환경](https://learn.microsoft.com/en-us/windows/apps/get-started/start-here) · [Windows App SDK 배포본](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads)

```powershell
Set-Location windows
dotnet build .\PenRelay.Desktop\PenRelay.Desktop.csproj -p:Platform=x64
.\PenRelay.Desktop\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\PenRelay.Desktop.exe
```

## Android에서 시작하기

JDK 21, SDK Platform 37.0, Build Tools 36.0.0 및 Platform Tools가 필요합니다. Gradle 9.3.1 Wrapper와 Kotlin 지원이 내장된 Android Gradle Plugin 9.1.1을 사용합니다. 최소 기기 버전은 Android 13(API 33)입니다. [AGP 호환표](https://developer.android.com/build/releases/agp-9-1-0-release-notes) · [Android SDK 도구](https://developer.android.com/studio)

Windows에서는 여러 프로젝트가 사용자별 SDK를 공유합니다. 이 PC의 SDK 위치는 `%LOCALAPPDATA%\Android\Sdk`입니다. 새 환경에서는 Android Studio SDK Manager 또는 공식 CLI로 필요한 패키지를 설치하고, 사용자 환경 변수 `ANDROID_HOME`에 SDK 폴더를 지정한 뒤 사용자 `Path`에 SDK의 `platform-tools` 폴더를 추가합니다. Android Studio의 SDK 위치와 기존 `android/local.properties`의 `sdk.dir`도 같은 폴더를 가리키도록 설정합니다. 새 PowerShell에서 `adb version`을 실행하면 사용 중인 실행 파일의 경로를 확인할 수 있습니다.

```powershell
# SDK Manager를 사용하는 새 환경의 설치 예시 (SDK 이용약관 확인 필요)
& "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" "platform-tools" "platforms;android-37.0" "build-tools;36.0.0"
```

저장소 루트에서 아래 빌드를 실행합니다. 기기 설치 단계는 태블릿에서 USB 디버깅 연결을 승인한 후 실행합니다.

```powershell
Set-Location android
.\gradlew.bat :sensor-diagnostics:assembleDebug
# APK: sensor-diagnostics/build/outputs/apk/debug/sensor-diagnostics-debug.apk
.\gradlew.bat :sensor-diagnostics:installDebug
```

태블릿에서 **펜 릴레이 센서 진단 → 기록 시작 → 검은 영역에 입력 → 기록 종료** 순서로 진행합니다. 기록 추출 명령, 실험 동작과 판정 조건은 [시험 계획](docs/TEST_PLAN.md)에 있습니다.
